## 🛠️ Troubleshooting / Fix Workflow

1. Update Steam and Moon Sweepers, then launch it from the game’s Steam Library page.
2. Restart Steam completely and check that the intended owning account is signed in.
3. Use Steam Properties > Installed Files > Verify integrity of game files.
4. Temporarily disable nonessential overlays and third-party mods for a clean launch test.
5. Check for current Windows graphics driver updates and a pending reboot.
6. If you see “requires Steam”, capture the exact dialog text; there is no published universal fix for that launch-week symptom.
7. For UnityPlayer crashes, record the Windows Event Viewer application error and GPU model for a developer report.

## ❓ FAQ

**Does a Steam-required dialog mean the game was not bought?**  
Not necessarily. Players have reported the message even after launching through Steam.

**Was every startup bug fixed in 1.0.4?**  
No. The published patch specifically mentions older Proton startup fixes.

**Should I reinstall immediately?**  
Try version verification and a clean launch first; reinstalling did not solve every reported issue.
